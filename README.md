# Болзооны урилга — жижиг асуулт

> **Жишээ загвар.** Нэр («Сараа», «Батаа»), дугаар нь жишээ — `CONFIG`-д өөрийнхөөр соль.
> Анх бодит захиалгаар хийгдэж, Netlify-д нийтлэгдсэн (2026-09-21).

«Надтай болзоонд явах уу?» Ганц карт. «Тийм» товч томорч, цэцэг дэлгэрнэ.
«Үгүй» товч хулгана ойртох бүрд зугтаана, 6 удаагийн дараа алга болно.

«Тийм» дарсны дараа **өдөр, цагаа сонгоно**. Сонгосныг нь нэг мөр болгож,
хуулах буюу мессежээр илгээх боломжтой.

Нэг файл: `index.html`. Build хэрэггүй, суулгах зүйлгүй.
**Давхар товшвол шууд нээгдэнэ.**

Гаднаас татдаг зүйл: Google Fonts (Cormorant Garamond, Onest), «Тийм» дарсны дараа YouTube тоглогч.
Зураг, номын сан татдаггүй — цэцэг, дүрс бүгд SVG.

## Юу засах вэ

`index.html`-ийн доод хэсэгт `const CONFIG = {` гэсэн мөр байна. **Зөвхөн түүнийг
засна.** Дээрх CSS, HTML-д хүрэх шаардлагагүй.

| Талбар | Юу |
|---|---|
| `eyebrow` | Дээд талын жижиг шошго |
| `ask` | Гол асуулт. `<em>үг</em>` гэж бичсэн үг ягаанаар, налуу гарна |
| `hints` | Зугтах бүрд ээлжлэн гарах тайлбарууд |
| `yes` · `no` | Товчны бичиг |
| `dodgeLimit` | Хэдэн удаа зугтсаны дараа «Үгүй» алга болох вэ |
| `noGoneNote` | «Үгүй» алга болоход гарах тэмдэглэл |
| `reply.title` | «Тийм» дарсны дараах гарчиг |
| `reply.lines` | Мөр бүр тусдаа догол мөр болно |
| `reply.photo` | Зургийн файлын нэр. Хоосон бол зураг огт харагдахгүй |
| `reply.signature` | Гарын үсэг |
| `song.youtube` · `song.start` · `song.label` | «Тийм» дарахад хуудсан дотор гарах YouTube тоглогч. `youtube` — `youtu.be/` дараах id, `start` — хэдэн секундээс. Android, компьютер дээр шууд эгшиглэнэ; iPhone дээр тоглуулах товчийг нэг дарна. «Дахин асуух» дарвал зогсоно. `youtube: ''` бол гарахгүй. Бичлэг embed зөвшөөрсөн байх ёстой |

### Өдөр, цаг сонгох — `CONFIG.when`

| Талбар | Юу |
|---|---|
| `enabled` | `false` болговол энэ хэсэг огт гарахгүй |
| `dayQuestion` · `timeQuestion` | Хоёр асуулт |
| `days` | Өнөөдрөөс эхлээд хэдэн өдөр санал болгох (7 бол долоо хоног) |
| `times` | Санал болгох цагууд. Жагсаалтыг хүссэнээрээ засна |
| `placeQuestion` · `places` | «Хаана?» асуулт ба сонголтууд. `label` — товч дээр, `say` — мессежид орох хэлбэр («кино үзэхээр»). `[]` бол асуулт гарахгүй |
| `pickedNote` | Сонгосны дараа доор гарах жижиг тэмдэглэл |
| `phone` | **Хоосон бол зөвхөн «Хуулах» товч гарна.** Дугаар бичвэл «Мессежээр илгээх» нэмэгдэж, SMS-ийн бичвэр бэлэн орно |
| `messageTemplate` | `{when}` — «Лхагва гаригийн 19:00 цагт», `{where}` — «кино үзэхээр», `{date}` — «9-р сарын 23» |

Эхний хоёр өдөр нь **Өнөөдөр**, **Маргааш** гэж, цаашаа гаригийн нэрээр гарна.
Огноо нь тухайн хүний утасны цагаар тооцогдоно — гар аргаар шинэчлэх шаардлагагүй.

Өнгөрсөн цаг сонгогдохгүй: оройхон нээвэл «Өнөөдөр»-ийн өнгөрсөн цагууд
харагдахгүй, бүх цаг нь өнгөрсөн бол «Өнөөдөр» огт гарахгүй, маргаашаас эхэлнэ.

### Зураг нэмэх

1. Зургаа энэ хавтас руу хуулна (жишээ нь `zurag.jpg`)
2. `photo: ''` → `photo: 'zurag.jpg'` болгоно
3. Босоо зураг илүү тохирно (4:5). 500 KB-аас бага байвал утсанд хурдан нээгдэнэ

Файл олдохгүй бол хоосон талбай үлдэхгүй — зураг нь автоматаар нуугдана.
